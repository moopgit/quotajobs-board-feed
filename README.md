# quotajobs-board-feed

The data file for the QuotaJobs partner board. The board app fetches `board-data.json` from here at load.

Standard (ruled 2026-10-26): the board's content is partner-private in substance. This file is public, so it carries only public-fit content — a derivation from the partners' private register with whole classes withheld or generalized (call summaries · payments detail · price figures · the partner's organization, company, and provider names). The register itself never leaves its private home.

This repo replaces an earlier data repo whose file carried partner-business detail; it starts clean, with no carried history.
